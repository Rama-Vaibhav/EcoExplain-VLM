# EcoExplain-VLM

A reproducible benchmark and leakage-controlled evaluation protocol for **evidence-grounded classification of relative vegetation change** with vision-language models (VLMs).

- **Where and when:** 366 forest patches in and around **Kanha Tiger Reserve**, India, matched dry seasons **January–February 2022 (T0) and 2023 (T1)**.
- **Model input:** two true-colour Sentinel-2 chips plus an evidence card (Sentinel-2 indices, Sentinel-1 backscatter, CHIRPS rainfall, ERA5-Land anomalies, NASADEM terrain).
- **Target:** a **relative ΔNDVI class**, `decline` | `stable` | `increase` (`candidate_class` in `dataset.jsonl`).

**GitHub:** [Rama-Vaibhav/EcoExplain-VLM](https://github.com/Rama-Vaibhav/EcoExplain-VLM) (`main`). **Ada:** `~/EcoExplain-VLM`, venv `~/venvs/ecoexplain`.

Every number below is regenerated by `scripts/review/stats_report.py` into `results/review/stats_report.md`; cite from that file. The current report is **V7** (kept outside this repository).

## 1. Highlights

| Finding | Evidence |
|---|---|
| The card's evidence is sufficient for the task | A two-threshold ΔNDVI rule fitted on training data reaches **94.5%** (random test), **98.2%** on unpadded values, and **90.7%** on held-out spatial blocks |
| The protocol detects and explains label leakage | Qwen2-VL-2B's original 56.4% came from the card's summary line: it followed that line's trend word on 15 of 16 patches where it disagreed with the label. Without the line: 32.7% (18 vs 5 discordant patches, p = 0.011, Holm 0.085) |
| Small VLMs apply a stated rule almost perfectly | With the ±0.02 rule in the prompt, Qwen follows it on 53/55 patches and returns checkable JSON |
| Explanation tuning is promising (pilot) | 16 self-generated examples: **61.8%** vs **43.6%** for a matched zero-shot control (13 vs 3, p = 0.021, Holm 0.128) |
| Explanation scores need a copy audit | Under the structured prompt, 73 of 157 scored claims copy the prompt's rule; consistency is 54.8% without them vs 75.8% with |
| Results reproduce exactly | Three earlier runs re-run on 31 Oct 2026 gave identical predictions on 55/55 patches |

The open challenge it measures: with leak-free inputs, small open VLMs (0.5–3.8B) perform at the level of a constant predictor. That leaves a gap of about 50 points to the evidence rule.

## 2. Dataset, labels and splits

- **366 patches**, ~640 m footprints, from a 640 m grid over the study rectangle. Construction:
  - 5,800 grid cells
  - 3,668 cells with ≥ 60% tree cover and ≤ 5% water in ESA WorldCover
  - 1,200 sampled candidates
  - 366 labelled patches
- **Labels** come from two percentile batches on the Earth Engine ΔNDVI:

  | Batch | Pool | q15 | q85 | Patches kept |
  |---|---|---|---|---|
  | 1 | 1,200 candidates | −0.0377 | +0.0031 | 296 |
  | 2 | remaining 900 | −0.0339 | −0.0014 | 70 |

  Each batch reproduces its own rule exactly (296/296, 70/70). Audit: `scripts/review/label_audit.py`.
- **Card values** are averages over a zero-padded 512 px canvas. They underestimate patch means by about 7%, and by up to 57% on 14 edge-clipped patches (`scripts/review/card_dilution_audit.py`).

| Split | Train / dev / test | Test classes (d / s / i) | Files |
|---|---|---|---|
| Random (stratified, seed 42) | 256 / 55 / 55 | 18 / 18 / 19 | `data/splits/` |
| Spatial (5×4 block grid, whole blocks held out) | 266 / 46 / 54 | 13 / 21 / 20 | `data/splits_spatial/` (`scripts/write_spatial_splits.py`) |

**Card versions** (`src/vlm_combos.py`, `src/vlm_evidence.py`):

| Version | Contents | Leak-free? |
|---|---|---|
| `full` | Ends with a summary line containing a trend word and `candidate_class=` | **No** |
| `evidence_only` | Removes that line and the closing class list | Yes |
| `compact` | A label-free numeric table, identical for every model | Yes |

`python scripts/check_no_leak.py` must print 0.

## 3. Results (random test n = 55; spatial test n = 54)

### 3.1 Zero-shot classification and reference rules (random test)

| Run | Input | Accuracy |
|---|---|---|
| Qwen2-VL-2B | evidence-only | 32.7% (18), all `stable` |
| Qwen2-VL-2B | compact | 32.7% (18), all `stable` |
| LLaVA-Interleave-0.5B | compact | **43.6%** (24), never `stable` |
| BLIP-2 OPT-2.7B | compact, stitched image | no parsable answer |
| PaliGemma-3B | NDVI line only (adapted input) | 36.4% (20) |
| Qwen2-VL-2B | **full card (leaky)** | 56.4% (31); re-run identical |
| Best constant | always `increase` | 34.5% (19) |
| Fixed ±0.02 rule | card ΔNDVI | 63.6% (35) |
| Label rule (batch 1) | card ΔNDVI / Earth Engine Δ | 72.7% (40) / 89.1% (49) |
| Fitted two-threshold rule | card ΔNDVI / unpadded mean | **94.5%** (52) / **98.2%** (54) |

PaliGemma is gated on Hugging Face and was not loaded for the leak-free runs.

### 3.2 Spatial test (n = 54; best constant = always `stable`, 38.9%)

| Run | Accuracy |
|---|---|
| Qwen2-VL-2B, compact / evidence-only (384 px) | 38.9% (21), all `stable` |
| LLaVA-Interleave-0.5B, compact | 27.8% (15) |
| Qwen2-VL-2B class LoRA trained on spatial train (Ada 50743) | 40.7% (22); vs matched control 1 vs 0, p = 1.0 |
| Rule fitted on spatial train, card / unpadded | **90.7%** (49) / 92.6% (50) |

### 3.3 Class LoRA (Qwen2-VL-2B, 16 balanced patches, evidence-only, 384 px)

| Run | Accuracy |
|---|---|
| Reported adapter (Ada 29575) | 36.4% (20); matched zero-shot control 32.7%; 2 vs 0, p = 0.50 |
| Repeats of the same sample (29571, 44523) | 36.4%, 34.5% |
| Five different samples, seeds 1–5 (Ada 50809) | 34.5–36.4% (19–20); each answers `stable` on 53–54/55 |
| Superseded: full card at train and test (2722446; 2690/2792) | 67.3%; 100%. **Both read the summary line.** Never cite them as vision results |

### 3.4 Explanations (random test)

| Setting | Class acc. | Claim consistency | Without copied rule text |
|---|---|---|---|
| Qwen, structured cite-only | 63.6% | 75.8% (119/157) | 54.8% (46/84) |
| LLaVA, structured cite-only | 41.8% | 71.1% (91/128) | 51.7% (31/60) |
| Qwen zero-shot, free-form, 384 px | 43.6% | 42.2% (164/389) | — |
| **Explanation LoRA** (Ada 24389), 384 px | **61.8%** | 50.5% (190/376) | — |

**What the explanation LoRA is:**
- **Teacher:** Qwen2-VL-2B.
- **Training targets:** 28 of 256 training justifications passed the checker. The first 128 training IDs contain 16 of those 28, and all 16 are decline examples.
- **Result:** it gets 17/18 decline and 17/19 increase patches right, but no stable patch.

"Claim consistency" is *directional claim consistency*: agreement between each claimed direction and the card. It is not faithfulness. Claim-level audit: `scripts/review/claim_audit.py` → `results/review/claims.csv`.

### 3.5 Statistics

- **Paired tests:** exact two-sided McNemar.
- **Multiple-testing correction:**
  - **Main family:** nine tests, Holm-adjusted together. The family was fixed before the matched-control runs.
  - **Supplementary family:** the seven later comparisons (spatial adapter, five sample seeds), Holm-adjusted separately.
- **Every run also has:** Wilson 95% intervals, per-class P/R/F1, macro-F1 and a confusion matrix.
- **Sensitivity checks:** results re-scored on the 49 rule-consistent and the 52 unclipped test patches.

## 4. Reproducing the numbers

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt        # plus torch torchvision transformers accelerate peft bitsandbytes

python scripts/review/label_audit.py
python scripts/review/card_dilution_audit.py
python scripts/review/claim_audit.py
python scripts/review/stats_report.py   # -> results/review/stats_report.{md,json} and report tables
python scripts/review/run_manifest.py   # -> results/review/run_manifest.md (inputs, precision, files per run)
```

**Model runs on a Mac** (Apple M4, MPS, fp16). Each run writes a new file and never overwrites an existing one:

| Script | Runs |
|---|---|
| `scripts/review/run_matched_controls.sh` | X1–X5: evidence-only 336/384 px, explanation control, 512-token run, reproduction check |
| `scripts/review/run_matched_controls_part2.sh` | X6, X7: full-card and compact re-runs |
| `scripts/review/run_spatial_matched_control.sh` | X8: spatial evidence-only control |

Explanations:

```bash
python scripts/run_explain.py --mode explain --prompt-style structured --combo qwen_vl_custom_mlp_qwen
python scripts/score_explanations.py
```

### Ada (GPU cluster)

```bash
cd ~/EcoExplain-VLM && source ~/venvs/ecoexplain/bin/activate
sbatch scripts/ada_slurm_qwen_balanced_smoke.sh     # class LoRA, 16 balanced, evidence-only
sbatch scripts/ada_slurm_qwen_spatial_lora.sh       # class LoRA on the spatial split
sbatch scripts/ada_slurm_qwen_seed_sweep.sh         # class LoRA, sample seeds 1-5
sbatch scripts/ada_slurm_explain_targets.sh         # teacher filter (2B)
sbatch scripts/ada_slurm_qwen_explain.sh            # explanation LoRA
```

- **Environment:** the jobs record `pip freeze` and the GPU name in `results/ada_*`. Recorded set-up: GTX 1080 Ti, torch 2.7.1+cu118, transformers 5.17.0, peft 0.21.0, bitsandbytes 0.50.2.
- **Memory:** use `--mem=16G` (32G exceeds the QoS limit).
- **Hugging Face downloads:** set `export HF_HUB_DISABLE_XET=1`. A 7B teacher does not fit the home quota.
- **LoRA settings:**
  - r = 8, α = 16
  - 4-bit NF4 during training, fp16 at evaluation
  - 384 px images
  - one epoch, four optimiser steps
  - the dev set is evaluated once, with no checkpoint selection

## 7. Reporting guide

**Accurate to say:**
- The evidence supports 91–95% with a fitted rule.
- The protocol traced the leaky 56.4% to the summary line.
- Leak-free zero-shot small VLMs perform at constant-predictor level on both splits.
- The class LoRA is level with its matched control, and this is reproducible across six training samples and the spatial split.
- The explanation LoRA's 61.8% vs 43.6% is a promising pilot (p = 0.021 before adjustment).

**Do not say:**
- That 56.4%, 67.3% or 100% are vision results. All three read the summary line.
- That the explanation LoRA gain is significant after Holm adjustment.
- That claim consistency measures faithfulness.
- That the labels were validated in the field or by a blind multi-expert audit.
